1Crear carpeta de backups en Drive
  1. En el celular o PC abrí drive.google.com
  2. Creá una carpeta, por ejemplo Discografia_Backups
  3. Ahí van a vivir los archivos .json exportados desde Discografía (editor)
  4. El Viewer siempre tomará el más reciente según la fecha y hora del nombre del archivo (ej. discografia_2026-09-30_0030.json)
2Copiar el ID de la carpeta
  1. Abrí la carpeta en Drive
  2. Mirá la barra de direcciones. La URL se ve así:
    https://drive.google.com/drive/folders/1ABC…xyz
  3. Copiá solo la parte 1ABC…xyz — ese es el FOLDER_ID
3Crear el proyecto en Apps Script
  1. Abrí https://script.google.com (con la misma cuenta de Google)
  2. Tocá Nuevo proyecto
  3. Borrá el código de ejemplo
  4. Tocá Copiar código abajo y pegalo en el editor
  5. Reemplazá PEGÁ_AQUÍ_EL_ID_DE_LA_CARPETA por tu FOLDER_ID
  6. Guardá el proyecto (💾) y poné un nombre, ej. DiscografiaBridge

var FOLDER_ID = 'PEGÁ_AQUÍ_EL_ID_DE_LA_CARPETA';

function doGet(e) {
  e = e || { parameter: {} };
  var action = (e.parameter.action || 'list').toLowerCase();
  try {
    if (action === 'list') return json_(listFiles_());
    if (action === 'get' || action === 'download') {
      var id = e.parameter.id;
      if (!id) return json_({ error: 'Falta parámetro id' });
      return json_(getFile_(id));
    }
    return json_({ error: 'Acción desconocida: ' + action });
  } catch (err) {
    return json_({ error: String(err && err.message ? err.message : err) });
  }
}

function listFiles_() {
  var folder = DriveApp.getFolderById(FOLDER_ID);
  var it = folder.getFiles();
  var files = [];
  while (it.hasNext()) {
    var f = it.next();
    var name = f.getName();
    if (!/\.json$/i.test(name)) continue;
    files.push({
      id: f.getId(),
      name: name,
      modifiedTime: f.getLastUpdated().toISOString(),
      size: f.getSize()
    });
  }
  return { files: files };
}

function getFile_(id) {
  var file = DriveApp.getFileById(id);
  var text = file.getBlob().getDataAsString('UTF-8');
  return JSON.parse(text);
}

function json_(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

Solo consulta del catálogo

  • Mostrar la metadata de tu colección personal de CDs
  • Abrir enlaces que ya estén guardados en la lista cargada

  • Descargar archivos de audio o video
  • Almacenar archivos multimedia en el dispositivo
  • Saltar sistemas de pago o DRM
  • Compartir archivos entre usuarios
  • Abrir dominios no oficiales (bloqueo automático)
